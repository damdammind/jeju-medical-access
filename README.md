# 제주 의료접근성 관측소 · HTML판 v1.2

파이썬·서버 없이 **폴더 하나**로 동작하는 판입니다. 서버판(`jeju_medical_v1.3`)과는 별개 폴더입니다.

## 실행
`dashboard.html`을 내려받아 더블클릭하면 됩니다. 파일 하나만 받아도 동작합니다.
- 공공데이터: `dashboard.html`에 내장된 인증키(같은 폴더에 `keys.js`가 있으면 그 키)로 열 때마다 최신 자료를 자동으로 불러옵니다. 불러오는 동안 위쪽에 "API 연결 중" 표시가 뜨고, 끝나면 "실시간 API · 직접 호출"로 바뀝니다.
- Claude 채팅: 오른쪽 아래 **✦ Claude에게 묻기**를 누르면 Claude API 키 입력 화면이 뜹니다. 각자 자기 키(`sk-ant-...`)를 넣으면 됩니다. 키는 그 브라우저에만 저장되고 파일에는 남지 않습니다.

## 키
- 공공데이터포털 인증키는 과제 공개용으로 `dashboard.html`과 `keys.js`에 일부러 넣어 두었으며 누구나 볼 수 있습니다. 다른 키를 쓰려면 `keys.js`를 고쳐 같은 폴더에 두면 그 키가 먼저 쓰입니다.
  ```
  window.JEJU_DATA_KEY = "공공데이터포털_인증키";
  ```
- **Claude API 키는 이 저장소 어디에도 넣지 마세요.** 공개되면 다른 사람이 써서 요금이 키 주인에게 청구됩니다.

## 주의
- 공공데이터 인증키는 하루 호출 수 한도가 있습니다. 한 번 열 때 약 50회를 부르므로, 여러 명이 자주 열면 한도에 닿을 수 있습니다 〔확인 필요: 포털 마이페이지에서 한도 확인〕.
- 공공데이터포털이 브라우저 직접 호출을 막으면 실시간 연결이 안 되고 내장 스냅샷(2026-11-01)으로 표시됩니다. 이때는 서버판을 쓰세요.
- 'API 연결' 탭에서 인증키를 직접 넣을 수도 있습니다.
