지금 데이터가 말하는 것

현재 조건으로 자동 작성한 핵심 발견. 조건이나 API 자료가 바뀌면 문장도 바뀝니다.

    읍·면, 동 지역, 제주 전체

    같은 지표를 세 범위로 나란히 봅니다.

    고령 인구 대비 의원 수

    점선은 제주 전체 평균. 막대를 누르면 프로필로 이동합니다.
    자료: 행정안전부 법정동별 인구, 건강보험심사평가원 병원정보 (data.go.kr)

    지표별 순위와 제주 평균

    지표를 고르면 순위가 다시 매겨집니다.

    제주 전체 대비 지수표 (전체 = 100)

    칸 색: 파랑은 접근성이 전체보다 나음, 빨강은 부족함. 고령화율은 높을수록 수요가 큰 것으로 봅니다. 열 제목을 누르면 정렬됩니다.

    고령화율과 고령 인구 대비 의원 수

    원 크기 = 총인구. 오른쪽 아래(고령화는 높고 의원은 적은 곳)가 우선 검토 대상입니다. 기준선은 제주 전체 값입니다.
    자료: 행정안전부, 건강보험심사평가원 (data.go.kr)

    사분면별 지역

    연도별 신규 개설 기관 (현재 운영 중)

    심평원 개설일자(estbDd) 기준. 이미 문을 닫은 기관은 API에 없어 포함되지 않습니다.

    누적 기관 중 읍·면 비중

    해마다 그해 말까지 개설된 기관 중 읍·면에 있는 비율. 고령 인구 중 읍·면 비중(점선)과 비교합니다.

    최근 5년 신규 개설은 어디로 갔나

    지역별 최근 5년 개설 수와, 그 지역이 제주 고령 인구에서 차지하는 비중을 비교합니다.

    내장 스냅샷 대비 API 변화 감지

    지금 불러온 API 자료를 기준 스냅샷과 기관 코드로 대조합니다.

    인구 10만 명당 휴일·야간 진료 기관

    자료: 국립중앙의료원 전국 병·의원 찾기 서비스, 행정안전부 (data.go.kr). 주소에서 지역을 뽑고, 없으면 좌표로 가장 가까운 심평원 기관의 지역을 씁니다.

    평일 진료 종료 시각 분포

    월요일 기준, 기관 수 대비 비율(%)

    권역별 휴일·야간 공급

    읍·면을 생활권으로 묶은 권역 단위. 지킴이 후보는 권역 안에서 기관이 가장 많은 읍·면입니다.

    지역 프로필

    성·연령 구조

    지역 인구 대비 비율(%). 테두리 표시는 제주 전체 비율

    전체·유형 평균 대비

    0 = 제주 전체와 같음. 오른쪽(파랑)일수록 접근성이 좋음

    지역 안의 의료기관

    심평원 기관 정보와 국립중앙의료원 진료시간을 이름·좌표로 맞춰 붙였습니다.

    의료기관 위치

    심평원 좌표(XPos·YPos). 지역을 고르면 그 지역 기관만 진하게 표시합니다. 추자면은 지도 북쪽 밖에 있습니다.
    자료: 건강보험심사평가원 병원정보서비스 (data.go.kr)

    취약 지역 판정 기준

    값을 바꾸면 판정과 정책 문장이 바로 다시 계산됩니다.

    연결 방식

    HTML판은 파일 하나로 동작합니다. 인증키는 이 브라우저에만 저장됩니다.
    ① 직접 호출
    같은 폴더의 keys.js에 넣어 둔 공공데이터포털 인증키로 열 때마다 자동으로 연결합니다. 다른 키를 쓰려면 아래 칸에 넣으면 됩니다. 이 HTML 파일이 apis.data.go.kr을 직접 부릅니다. 파이썬이나 서버가 필요 없습니다.
    ② 내장 스냅샷
    인증키가 없거나 API에 닿지 않을 때 쓰는 기준 자료(수집일 —).
